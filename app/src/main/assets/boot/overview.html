Boot scripts 起動

Mayonaka runs whatever it finds in ~/.termux/boot/ when the device starts up.

Usage

  • Create the directory: mkdir -p ~/.termux/boot
  • Drop executable scripts in it. They run in sorted order, so name them 10-first, 20-second and so on.
  • Each script runs as a background job, not in a visible session.
  • Run termux-wake-lock first if the device must stay awake.

Example

To start an sshd server and hold a wake lock at boot, put this in ~/.termux/boot/10-sshd:

#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
sshd

Then make it executable:

chmod +x ~/.termux/boot/10-sshd

If nothing runs

Some vendors — Samsung included — aggressively restrict what may start at boot. If your scripts do not run, put Mayonaka on the never sleeping apps list and exclude it from battery optimisation:

Settings → Battery → Background usage limits → Never sleeping apps → add Mayonaka

Scripts are logged under the termux tag, so logcat -s termux from an adb shell will show what fired.

Upstream
